Engineering simulators for robots, scanners, agents & learning machines

Twelve hands-on web apps across mechatronics, medical imaging, assistive robotics, artificial intelligence, agentic systems, research methods, digital health and energy. Each one is a working simulator: tune a servo, plan a robot arm's motion, reconstruct CT and MRI scans, drive a smart wheelchair, control a prosthetic hand with EMG, watch neural networks learn, stress-test LLM agent workflows, run a meta-analysis, manage an EV battery pack or catch falls with a wearable. Every algorithm is written from scratch, and the apps run in your browser.

How these apps are built

From first principles

There are no frameworks or numeric libraries. FFTs, reconstruction algorithms, planners, classifiers, back-propagation and the genetic algorithm, the event simulator and the meta-analytic estimators are all implemented by hand in plain JavaScript, so the source reads like an annotated textbook.

Tested cores

Each app keeps its maths in a DOM-free *-core.js module that also runs in Node.js. Examples of what is checked: FFT against NumPy, gradients against finite differences, meta-analysis against R's metafor, power against G*Power.

Runs anywhere

The apps are static HTML, CSS and JS with self-hosted fonts. Open index.html from disk, serve the folder, or deploy to GitHub Pages. There is no build step, no API key and no server.
